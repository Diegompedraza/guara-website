TECHNOLOGY

A software-first architecture for Human-State Intelligence.

GUARA separates what the camera observes from how evidence is measured, interpreted over time and turned into operational information. The intelligence layer, not a particular device, defines the platform.

Perception

Computer vision provides raw observations of visual signals such as eyes, blinking, gaze and head orientation. Perception is treated as one layer, so sensing approaches and hardware can evolve without redefining the rest of the platform.

Observability and measurement

Measurements need context, quality and confidence. The architecture lets downstream reasoning distinguish strong evidence from uncertain, incomplete or degraded signals.

Temporal analysis

Human state evolves over time. GUARA reasons about persistence, transitions and recovery rather than treating every frame as an independent decision.

Local processing

Analysis runs on the device. This reduces the need to transmit video, keeps critical detection working with limited or no connectivity, and supports privacy-oriented, compliance-conscious architectures.

Hardware profiles

The current reference implementation, GUARA Professional, runs on Raspberry Pi-class embedded hardware. An Android implementation has been demonstrated in closed testing. Higher-performance Edge platforms, such as NVIDIA Jetson-class devices, are under evaluation. None of these profiles defines GUARA: they are environments where the same intelligence runs.

Modular software evolution

GUARA is evolving from its first embedded implementation toward a more modular software architecture, with greater hardware decoupling and integration tooling for third parties. This work is in development; compatibility with a specific infrastructure is confirmed through a technical assessment.
